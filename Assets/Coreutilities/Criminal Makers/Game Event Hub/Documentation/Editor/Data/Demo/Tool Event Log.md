# Tool: Event Log

Now when the bus arrives at the bus stop, the event will be published. However, passengers are not reacting to it yet, but you can see the event in the **Event Log**.

Go ahead and try it, start the game and move the bus with `A` and `D` keys. When the `bus arrives at the bus stop`, you will see the event in the log.

> You can find the log tool under: Tools > Game Event Hub > Event Log
