# Welcome to Game Event Hub demo

In this demo, we will show you a basic example of how to create a **custom event**, then how to **publish** it and finally how to **subscribe** to it.


To start, open the scene under `Game Event Hub/Demo/GameEventHubDemo` and follow the next pages.

> The scene is in 2D mode, so you may want to switch to 2D mode in the scene view. (press key 2 or click the 2D button in the scene view)
