# 04. Dynamic subscriber

This example shows how to create a dynamic subscriber.


## See it in action

1. Open the scene under `Game Event Hub/Examples/04 Dynamic Subscriber`

2. Open the monitor tool under `Tools > Game Event Hub > Monitor`

3. Start the game.

4. You should see in the monitor that a subscription appears and disappears every `3 seconds`

5. Press `SPACE` when the subscription is active. You should see a message in the middle of the screen.

6. Press `SPACE` when the subscription is inactive. You should not see any message.


## Dynamic subscriber

- Check in the `Hierarchy` for a GameObject named `Canvas > Dynamic Event subscriber` and open the script `OnKeyPressDynamicSubscriber.cs`

```csharp

public class OnKeyPressDynamicSubscriber : MonoBehaviour
{
    IEnumerator ForeverSubAndUnsub()
    {
        while (true)
        {
            Action unsub = GameEventHub.Listen(this, (OnKeyPressed e) =>
            {
                canvasGroup.alpha = 1;
            });
            
            yield return new WaitForSeconds(3);
            
            // Disconnect this object from the GameEventHub
            unsub();
            
            yield return new WaitForSeconds(3);
        }
    }
}

```

Here is the code responsible for creating a dynamic subscriber.

`GameEventHub.Listen` is a method that creates a subscription to an event. It returns an `Action` that can be called to unsubscribe from the event.

As a parameter, it receives the subscriber object (generally `this`), and a lambda that will be called when the event is emitted. **The lambda must have a single parameter that matches the event type**.

## Unsubscribing

To unsubscribe from an event, you must call the `Action` returned by `GameEventHub.Listen`. You can store that `Action` in a variable and call it when you want to unsubscribe.

Alternatively, you can use `GameEventHub.Unbind` to unsubscribe from all events (static and dynamic)
