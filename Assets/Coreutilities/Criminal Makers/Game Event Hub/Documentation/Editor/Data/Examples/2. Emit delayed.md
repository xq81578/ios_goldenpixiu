# 02. Emit delayed

This example shows how to emit an event with a delay.


## See it in action

1. Open the scene under `Game Event Hub/Examples/02 Emit delayed`

2. Start the game.

4. Press `SPACE` to emit an event. You should see a message in the console with a delay of `0.5 seconds`.


## Event emitter

- Check in the `Hierarchy` for a GameObject named `Event Emitter` and open the script `EmitEventWithKeyDelayed.cs`

```csharp

public class EmitEventWithKeyDelayed : MonoBehaviour
{
    public float secondsToWait = 0.5f;
    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            new OnKeyPressed().PublishDelayed(this, secondsToWait);
        }
    }
}
```

Here is the code responsible for emitting the event. It's a simple `MonoBehaviour` that listens for the `SPACE` key press and emits the event `OnKeyPressed` with a delay of `0.5 seconds`.

> Instead of using Publish() it's using PublishDelayed() with a delay of `0.5 seconds`. 
> The event will be emitted even if the emitter is destroyed before the delay is over.
