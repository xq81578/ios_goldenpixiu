# 05. Shared vs Unique events

This example shows the difference between shared and unique events.


## See it in action

1. Open the scene under `Game Event Hub/Examples/05 Shared vs Unique`

2. Take a look at the `Unity console`, make sure it's clear.

3. Start the game.

4. Press `SPACE` to emit an event as `Shared`. You should see a count in the console that increases by 1 by each subscriber.

5. Press `F` to emit an event as `Unique`. You should see that every message in the console has the same value.


## Counter Increaser Subscriber

- Check in the `Hierarchy` for a GameObject named `Counter event receiver` and open the script `CounterIncreaserSubscriber.cs`

```csharp

public class CounterIncreaserSubscriber : MonoBehaviour
{
    [OnGameEvent]
    private void IncreaseCounter(OnCounter e)
    {
        e.counter++;
        Debug.Log("Counter increased to " + e.counter);
    }
}

```

Here is the code responsible for reacting to the event. It's a simple `MonoBehaviour` that listens for the `OnCounter` event and increments the payload `counter` by 1.

## Counter Emitter

- Check in the `Hierarchy` for a GameObject named `Event Emitter` and open the script `CounterEventEmitter.cs`

```csharp
public class CounterEventEmitter: MonoBehaviour
{
    private void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            new OnCounter()
                .Shared()
                .Publish(this);
        }

        if (Input.GetKeyDown(KeyCode.F))
        {
            new OnCounter()
                .Publish(this);
        }
    }
}
```

- When the `SPACE` key is pressed, the event is emitted as `Shared`. This means that the event instance will be shared among all subscribers. The payload `counter` will be incremented by 1 by each subscriber.

- When the `F` key is pressed, the event is emitted as `Unique` (default behavior). This means that a new instance of the event will be created for each subscriber. The payload `counter` will be the same for all subscribers.
