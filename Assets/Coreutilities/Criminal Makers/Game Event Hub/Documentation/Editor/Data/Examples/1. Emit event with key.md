# 01. Emit event with key

This is the first step to understand how the event mechanism works.


## See it in action

1. Open the scene under `Game Event Hub/Examples/01 Emit event on key`

2. Start the game.

3. Press `SPACE` to emit an event

4. A message will be displayed in the center of the screen


## Emission of the event

- Check in the `Hierarchy` for a GameObject named `Event Emitter`

```csharp

public class EventEmitOnKey : MonoBehaviour
{
    // Update is called once per frame
    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            new OnKeyPressed().Publish(this);
        }
    }
}

```

Here is the code responsible for emitting the event. It's a simple `MonoBehaviour` that listens for the `SPACE` key press and emits an event of type `OnKeyPressed`.


## Subscription

- Check in the `Hierarchy` for a GameObject named `Event Subscriber` (it's a child of `Canvas`)

Inside `OnKeyPressSubscriber.cs` you will find the following code:

```csharp

private void OnEnable()
{
    GameEventHub.Bind(this);
    StartCoroutine(ForeverFadeOut());

}

private void OnDisable()
{
    GameEventHub.Unbind(this);
}

```

This is responsible for connecting and disconnecting the `GameObject` to the `GameEventHub`. It uses the `GameEventHub.Bind()` and `GameEventHub.Unbind()` methods to do so. In this case, the subscription is **STATIC** because of the use of the attribute `[OnGameEvent]`


Then, a little further down, you will find the method that will be called when the event is emitted:

```csharp

[OnGameEvent(SubscriberPriority.Medium)]
private void OnKeyPressed(OnKeyPressed e)
{
    canvasGroup.alpha = 1;
}

```

This method is decorated with the attribute `[OnGameEvent]` and will be called when the event `OnKeyPressed` is emitted. The method will set the `alpha` of the `CanvasGroup` to `1`, making it visible. The first parameter of the method is the event itself, which will be automatically injected by the `GameEventHub`.
