# 06. Emit with filters

This example shows how to emit an event with filters.


## See it in action

1. Open the scene under `Game Event Hub/Examples/06 emit with filters`

2. Start the game.

4. Move the bus using `A` or `D` and press `SPACE` to emit an event.

5. You should always hear the bus honking

6. Passengers will only react to the event if the bus is close enough.


## Event emitter

- Check in the `Hierarchy` for a GameObject named `bus` and open the script `Bus2.cs`

```csharp

public class Bus2 : MonoBehaviour
{
    private void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            // Honk the horn so the passengers get up in the bus
            new OnBusHonk()
                .WithFilter(new InsideCollider2D(zoneToEmitEvent2D))
                .Publish(this);
        }
    }
}
```

Here is the code responsible for emitting the event. It's a simple `MonoBehaviour` that listens for the `SPACE` key press and emits the event `OnBusHonk` with a filter `InsideCollider2D(zoneToEmitEvent2D)`.


## Why Honk audio will always play?

- Check in the `Hierarchy` for a GameObject named `Honk Audio` and open the script `BusHonkPlayer.cs`

```csharp
public class BusHonkPlayer : MonoBehaviour
{
    [OnGameEvent(SubscriberPriority.Essential)]
    private void PlayBusHonk(OnBusHonk e)
    {
        audioSource.Play();
    }
}
```

The honk audio will always play because the subscriber has a priority of `Essential`. This means that the subscriber will always receive the event, regardless of the filter.


## How does the filter work?

Open the script `InsideCollider2D.cs`.

```csharp
public class InsideCollider2D: ISubscriberFilter
{
    private Collider2D _collider;

    public InsideCollider2D(Collider2D collider)
    {
        _collider = collider;
    }

    public List<AbstractAttributeBound<OnGameEvent>.BindingInfo> Filter(GameEvent originalEvent, List<AbstractAttributeBound<OnGameEvent>.BindingInfo> bindings)
    {
        bindings.RemoveAll(bind =>
        {
            GameObject subscriberGameObject = SubscriberFilterHelper.ExtractGameObject(bind.Subscriber);
            return subscriberGameObject == null || !_collider.bounds.Contains(subscriberGameObject.transform.position);
        });
        return bindings;
    }

    public override string ToString()
    {
        return "InsideCollider2D";
    }
}
```

- It receives a `Collider2D` as a parameter in the constructor.

- The `Filter` method is responsible for removing the bindings that are not inside the `Collider2D` bounds.

- The `ToString` method is used to display the filter name in the log


> You can create your own filters by implementing the `ISubscriberFilter` interface in any plain C# class.
