# 03. Cancel event

This example shows how to stop an event from being propagated to other subscribers.


## See it in action

1. Open the scene under `Game Event Hub/Examples/03 cancel event`

2. Start the game.

3. Press `SPACE` to emit an event

4. A message will be displayed in the top of the screen saying that the event was canceled.

5. Disable inside the `Canvas` the `Event canceler` game object.

6. Press `SPACE` again. Now you should see a message in the middle of the screen.


## Cancelation of the event

- Check in the `Hierarchy` for a GameObject named `Event canceler` and open the script `OnKeyPressCancel.cs`

```csharp

public class EventEmitOnKey : MonoBehaviour
{
    [OnGameEvent(SubscriberPriority.High)]
    private void OnKeyPressed(OnKeyPressed e)
    {
        e.StopPropagation();
        canvasGroup.alpha = 1;
    }
}

```

Here is the code responsible for stopping the propagation of the event. It's a simple `MonoBehaviour` that listens for the `SPACE` key press and calls the method `StopPropagation()` on the event.

> Note: In this case, the cancelation will happen for subscribers with a priority lower than SubscriberPriority.High.


## Other subscriber

- Check in the `Hierarchy` for a GameObject named `Event Subscriber` (it's a child of `Canvas`)

Inside `OnKeyPressSubscriber.cs` you will find the following code:

```csharp

[OnGameEvent(SubscriberPriority.Medium)]
private void OnKeyPressed(OnKeyPressed e)
{
    canvasGroup.alpha = 1;
}

```

Here is the code responsible for reacting to the event. It's a simple `MonoBehaviour` that listens for the `OnKeyPressed` event and sets the `alpha` of the `CanvasGroup` to `1`.

> Note: In this case, the subscriber has a priority of Medium which is lower than High. So, the event will be canceled before reaching this subscriber.
