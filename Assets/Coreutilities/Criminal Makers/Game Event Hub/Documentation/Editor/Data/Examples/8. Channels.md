# 08. Channels

This example shows how to set a channel for an event and following inside the `Log tool`.

> Important: Please notice, that channels doesn't affect the event emission / subscription, it's just a way to filter the events in the `Log tool`.


## See it in action

1. Open the scene under `Game Event Hub/Examples/08 Channels`

2. Open the `Log Tool` (Make sure the filter `Event raised` is ON)

3. Start the game

4. You should see a lot of events being raised, making the `Log tool` very hard to read and follow.

5. In the `Channel filter`, write `Player` and press `Enter`

6. You should see only the events raised by the `Player` GameObject.

7. Add another channel filter, write `Enemy` and press `Enter`

8. You should see only the events raised by the `Enemy` GameObject.

9. Remove the filters by pressing the `X` button on the right side of each channel name, to see all events again.


> As you probably noticed, channels are kept in lower case to simplify the filtering process. This means that `Player` and `player` are the same channel.


## Setting channel using attribute

- Open the script `OnPlayerMove`

```chsarp

[DefaultChannel("Player")]
public class OnPlayerMove : GameEvent
{
}

```

All events of type `OnPlayerMove` will be raised in the `Player` channel by default. This can be overriden before raising the event, if needed using `SetChannel`.






## Setting channel using SetChannel

Open the script `OnHealthChange`

```

public class OnHealthChange: GameEvent
{
}

```

As you can see, this event doesn't have a default channel, so it will use the `Default` channel defined in the `GameEvent` class:

```

[Serializable, DefaultChannel("Default")] // <-- Here
public abstract class GameEvent : ICloneable
{
    ...
}

```

Finally, if you open the script `PublishContinuously`, inside the `Publish` coroutine, you can see that the channel is being set:

```

private IEnumerator Publish()
{
    while (true)
    {
        gameEvent.SetChannel(channel).Publish(this);
        float rate = Random.Range(minMaxRate.x, minMaxRate.y);
        yield return new WaitForSeconds(rate);
    }
}

```

If the event is null or empty, it will attempt to use the one defined in the class. If the class doesn't have a channel defined, it will use the `Default` from the `GameEvent` class.
