# 1.5.0

## New integration: Unity Timeline

There is a new integration available for the Game Event Hub: Unity Timeline. This integration allows you to use the Game Event Hub within Unity's Timeline system, enabling you to publish events from clips.

It can be found at `Assets/Criminal Makers/Game Event Hub/Utilities/Timeline` as a `unitypackage` file. To install it, simply double-click the package file and import the files.

You will find in the extracted files a folder named `Examples` that contains a sample scene demonstrating the usage.

> Please make sure Timeline is installed in your project before importing the package.

> You can also safely delete this integration if you do not need it.
