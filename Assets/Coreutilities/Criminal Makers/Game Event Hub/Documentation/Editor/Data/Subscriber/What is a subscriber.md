# What is a subscriber?

A subscriber is a piece of code that listens for events and reacts to them.

Subscribers are not limited to `Monobehaviours`, any class can be a subscriber.

- Monobehaviours

- Scriptable Objects

- Editor Windows

- Inspectors

- Plain C# classes

Subscribers can be `static` or `dynamic`.

> As an example, the tools included in Game Event Hub are subscribers that listen for events and react to them.
